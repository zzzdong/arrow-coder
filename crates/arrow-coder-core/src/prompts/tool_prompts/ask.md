Use `ask` when you need clarification from the user or want to present options for a decision.

**When to use:**
- Ambiguous requirements or unclear scope
- Multiple valid approaches exist
- Need user confirmation before significant changes
- Want to validate assumptions

**Structure:**
- `question`: Clear, specific question
- `options`: 2-4 choices with brief labels and descriptions
- An "Other" option is automatically added for free text input

**Best practices:**
- Ask specific questions, not open-ended ones
- Present clear trade-offs in option descriptions
- Default to the simplest option
- Don't ask for confirmation on trivial changes
