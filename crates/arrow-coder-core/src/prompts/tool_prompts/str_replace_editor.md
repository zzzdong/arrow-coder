# str_replace_editor

一个面向文件的编辑器，提供四个命令。所有路径使用**绝对路径**。

## 命令

### view
查看文件（带行号）或列出目录。
- `path`: 文件或目录的绝对路径。
- `view_range`（可选）: `[起始行, 结束行]`，1 起始、含端点。省略则查看整个文件。
- 文件返回带行号的内容；目录返回浅层列表（两层，忽略隐藏/依赖缓存目录）。
- 显示的行内容保留制表符，可直接作为 `str_replace` 的字面量输入。

### create
创建一个新文件。
- `path`: 新文件绝对路径。
- `file_text`: 完整文件内容。文件已存在则拒绝。

### str_replace
用字面量文本精确替换文件内容（不含 `replace_all`）。
- `path`: 文件绝对路径。
- `old_str`: 要匹配的字面量文本，**必须在文件中恰好出现一次**。
- `new_str`: 替换后的字面量文本。
- 匹配 0 次或多于 1 次都会失败并报错。若失败，先用 `view` 查看实际内容，再提供足够上下文的 `old_str`。

### insert
在指定行号处插入文本（插入到该行之前）。
- `path`: 文件绝对路径。
- `insert_line`: 1 起始的行号，文本插入到该行之前。
- `new_str`: 要插入的文本（不自动补尾换行）。

## 使用原则
- 每次先 `view` 确认当前内容，再执行修改，避免 `old_str` 失配。
- 修改前用唯一上下文锁定 `old_str`，保证精确匹配。
- 修改操作是原子的：写入后校验，失败会回滚原内容。
